# 🦆 QuackCode - QR Code Styling

O **QuackCode** é um gerador de QR Codes profissional e altamente personalizável, construído com React e integrado com o Firebase para fornecer uma experiência completa de gerenciamento de códigos.

## ✨ Funcionalidades

- **Personalização Total:** Altere cores, formas dos pontos, estilos das quinas e adicione logos centrais.
- **Integração Firebase:**
  - **Authentication:** Login seguro com Google.
  - **Cloud Firestore:** Salve seus designs e acesse-os de qualquer lugar.
  - **Cloud Storage:** Upload de logomarcas personalizadas diretamente para a nuvem.
  - **Remote Config:** Mensagens e links dinâmicos atualizáveis sem novo deploy.
- **Multi-idioma:** Suporte completo para Português, Inglês e Espanhol.
- **Modo Escuro:** Interface moderna e confortável (DarkMode por padrão).
- **Exportação:** Baixe seus códigos em PNG, SVG ou JPEG.

## 🚀 Tecnologias Utilizadas

- [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Firebase](https://firebase.google.com/) (Auth, Firestore, Storage, Config)
- [qr-code-styling](https://www.npmjs.com/package/qr-code-styling)
- [Lucide React](https://lucide.dev/) (Ícones)
- [Zustand](https://github.com/pmndrs/zustand) (Estado Global)

## 📦 Como rodar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/QuackCode.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
